# Overview
This project develops an LLM-based summarization pipeline leveraging [Facebook’s bart-large-cnn model](https://huggingface.co/facebook/bart-large-cnn) fine-tuned for domain-specific transcript summarization. The goal is to generate concise, semantically faithful summaries by combining extractive and abstractive methods — ideal for long-form spoken or financial content such as podcasts, meetings, or SEC filings.

# Dataset
The project leverages the [gretelai/gretel-financial-risk-analysis-v1 dataset](https://huggingface.co/datasets/gretelai/gretel-financial-risk-analysis-v1) — a synthetic corpus of financial risk analysis text.
This dataset was generated by fine-tuning Phi-3-mini-128k-instruct on 14,306 SEC filings (10-K, 10-Q, and 8-K reports from 2023–2024) using differential privacy techniques. The resulting synthetic data captures the structure, tone, and analytical depth of real financial documents while ensuring that sensitive information is protected.
